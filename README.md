# 2027 상반기 K프랜차이즈 KFCEO 명품 19기 교육과정 신청 시스템

한국프랜차이즈산업협회 공식 CEO교육 프로그램의 온라인 신청 및 관리 시스템입니다.

## 로컬 실행 (추가된 개발 환경)

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```bash
npm start
```

- 메인: http://127.0.0.1:3000
- 신청: http://127.0.0.1:3000/apply.html
- 관리자: http://127.0.0.1:3000/admin.html (기존 비밀번호: `ceo7165`)
- 종료: 실행 터미널에서 `Ctrl+C`
- 개발 모드: `npm run dev`
- 검증: `npm test`

`server.cjs`가 정적 페이지와 `/tables/applications` API를 제공합니다.
신청 데이터는 첫 신청 시 생성되는 `data/applications.json`에 저장되며 재실행 후에도 유지됩니다.
이 파일을 복사하면 로컬 데이터를 백업할 수 있습니다. 기존 서비스 데이터는 압축파일에 포함되어 있지 않습니다.
서버는 이 PC에서만 접속 가능한 `127.0.0.1`로 실행되며, 기존 브라우저 기반 관리자 로그인을 사용하는 로컬 개발용 환경입니다.
Windows PowerShell에서 포트를 바꾸려면 `$env:PORT=3001; npm start`를 실행하세요.

SMS는 인증정보가 없는 기본 상태로 발송되지 않습니다. 폰트·아이콘·이미지·엑셀 라이브러리는 외부 주소를 사용하므로 인터넷 연결이 필요합니다.

## 📋 프로젝트 개요

### 프로젝트 목표
- 교육과정 참가자들이 온라인으로 편리하게 신청할 수 있는 시스템 제공
- 관리자가 신청자 정보를 효율적으로 관리할 수 있는 대시보드 제공
- 자동 할인 계산 및 결제 금액 산출 기능 제공
- **SMS 알림을 통한 실시간 신청 알림**

### 주요 기능
1. **교육과정 안내** - 모집요강, 교육내용, 혜택 정보 제공
2. **온라인 신청** - 신청자 정보 입력 및 자동 할인 계산
3. **관리자 대시보드** - 신청자 관리, 통계, 엑셀 다운로드
4. **SMS 알림** - 신청 시 관리자에게 자동 SMS 발송 (네이버 클라우드 SENS)

### 1. 메인 페이지 (index.html)

- **하단 고정 네비게이션**: 교육소개, 교육내용, 혜택안내, 문의, 관리자 메뉴

- **모집요강**
  - 교육 기간: 2027년 3월 ~ 27년 6월 (매주 월요일 14:00~17:00)
  - 교육 장소: 서울특별시 영등포구 국회대로 70길 15-1 극동VIP빌딩 404~410호

- **주요 교육내용**: 프랜차이즈 미래 경영 전략, 트렌드 & 마케팅, 글로벌 진출, CEO 토크쇼

### 2. 신청 폼 (apply.html)
- **하단 고정 네비게이션**: 홈, 교육소개, 교육내용, 문의, 관리자 메뉴
- **신청자 정보 입력**
  - 이름, 연락처 (자동 포맷팅), 이메일, 회사명, 직책
  - **KFCEO 업종 구분** (드롭다운 선택)
    - 프랜차이즈업, 법무법인, 세무회계, 노무법인
    - 물류업, 제조업 (9개 카테고리), 도소매업 (9개 카테고리)
    - 서비스업 (4개 카테고리), 정보통신업 (4개 카테고리)
    - 그 외 기타 (직접 입력)
- **할인 혜택 선택**
  - 20% 할인 항목 (체크박스)
  - 10% 할인 항목 (체크박스)
  - 중복 선택 가능, 최대 할인율 자동 적용
- **자동 결제 금액 계산**
  - 기본 교육비: 4,500,000원
  - 할인 금액 자동 계산
  - 부가세 (10%) 자동 계산
  - 최종 결제 금액 실시간 표시
- **폼 검증**
  - 필수 항목 검증
  - 이메일 형식 검증
  - 연락처 형식 검증 (010-0000-0000)
  - 업종 선택 필수 (기타 선택 시 직접 입력)
- **API 연동**: RESTful Table API를 통한 데이터 저장
- **SMS 알림**: 신청 완료 시 관리자에게 자동 SMS 발송

### 3. 관리자 로그인 (admin.html)
- **비밀번호 인증**: 관리자 전용 비밀번호 (ceo7165)
- **세션 관리**: sessionStorage를 통한 로그인 상태 유지
- **보안**: 미인증 접근 차단

### 4. 관리자 대시보드 (dashboard.html)
- **통계 대시보드**
  - 총 신청자 수
  - 상태별 신청자 수 (대기중, 승인, 거부, 결제완료)
  - 실시간 통계 업데이트
- **신청자 관리**
  - 신청자 목록 테이블 (업종 포함)
  - 상태 필터: 전체, 대기중, 승인, 거부, 결제완료
  - 검색 기능: 이름, 회사명으로 검색
- **신청자 작업**
  - 상세보기: 신청자의 모든 정보 확인 (업종 정보 포함)
  - 상태 변경: 신청 상태 변경 (대기중 → 승인 → 결제완료 등)
  - 삭제: 신청 데이터 삭제 (확인 모달 포함)

  - 필터링된 신청자 목록을 엑셀 파일로 다운로드

## 🔌 API 엔드포인트

### RESTful Table API 사용

#### 1. 신청 생성
```
POST /tables/applications
Content-Type: application/json

{
  "name": "홍길동",
  "phone": "010-1234-5678",
  "email": "hong@example.com",
  ...
}
```

#### 2. 신청 목록 조회
```
GET /tables/applications?page=1&limit=100
GET /tables/applications?search=홍길동
GET /tables/applications?sort=application_date
```

#### 3. 신청 상세 조회
```
GET /tables/applications/{record_id}
```

#### 4. 신청 상태 변경
```
PATCH /tables/applications/{record_id}
Content-Type: application/json

{
  "status": "승인"
}
```

#### 5. 신청 삭제
```
DELETE /tables/applications/{record_id}
```
